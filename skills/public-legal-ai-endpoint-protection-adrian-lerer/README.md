# Public Legal-AI Endpoint Protection by Ignacio Adrián Lerer

A public Lawve Skill for reviewing AI-backed web endpoints before launch or material change.

It checks request boundaries, authentication, rate and spend controls, input limits, server-side model/tool selection, error handling, logging, kill switches, rollback, and human approval points.
