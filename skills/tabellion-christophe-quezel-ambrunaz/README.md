# Overview

Transforme un modèle juridique (.docx ou .odt : contrat, conclusions, assignation, courrier type, procès-verbal…) en formulaire HTML autonome, exécuté hors ligne, qui produit sans IA le document complété, fidèle au modèle, dans son format d'origine : parties optionnelles et alternatives, listes répétées, accords, montants et dates en lettres, calculs, numérotation et renvois. Déclencher dès que l'utilisateur veut « transformer ce modèle en formulaire », « automatiser un modèle », un « modèle à remplir » ou un « générateur d'actes », réutiliser régulièrement un contrat ou une trame, ou demande « fais-moi un modèle de … à remplir » ; aussi pour faire évoluer un formulaire tabellion existant. Pas pour compléter une seule fois un document. Compétence créée par Christophe Quézel-Ambrunaz, Université Savoie Mont Blanc (V.1.1).
