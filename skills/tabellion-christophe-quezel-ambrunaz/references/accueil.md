# Message d'accueil

À présenter au premier déclenchement, en reprenant ce texte ou en l'adaptant légèrement au contexte. Ton sobre, sans formule d'accroche.

---

**Tabellion** transforme un modèle de document (contrat, trame de conclusions, assignation, courrier type) en un formulaire qui s'ouvre dans votre navigateur. Vous y saisissez les informations du dossier ; le formulaire produit le document complété, au format de votre modèle (Word ou OpenDocument), sans intelligence artificielle et sans connexion. Rien de ce que vous saisissez ne quitte votre ordinateur.

Le travail se déroule en quatre temps :

1. Vous me transmettez le modèle, en .docx ou en .odt. **Déposez de préférence un modèle anonymisé** : un document type, sans nom de client ni donnée d'un dossier réel. Je ne vérifie pas ce point à votre place.
2. Je repère les éléments variables, les passages optionnels ou alternatifs, les listes à répéter, les accords et les calculs. Je vous pose les questions nécessaires, notamment sur toute règle de calcul : je n'en applique aucune que vous n'ayez validée.
3. Je vous remets le modèle balisé. Les balises y sont surlignées et lisibles, et vous pouvez les corriger vous-même dans Word avant validation.
4. Je construis le formulaire et le teste sur des données fictives. Vous recevez un fichier .html à conserver, accompagné du modèle balisé, qui permet de le faire évoluer.

Si vous le souhaitez, je peux aussi vérifier l'actualité des références citées dans votre modèle (articles, montants) avant de le baliser.

Cette compétence donne ses meilleurs résultats avec le modèle Claude Opus.

Une seule discipline est attendue de votre part. Le formulaire conserve votre dossier dans le navigateur, mais la seule sauvegarde fiable est le fichier .json qu'il vous propose d'enregistrer. Ce fichier n'est pas chiffré : classez-le comme une pièce du dossier. Il peut être rouvert dans tout autre formulaire tabellion, pour réutiliser les mêmes parties dans un autre acte.
