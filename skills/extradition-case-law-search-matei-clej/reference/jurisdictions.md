## Reading this

Selecting it alone returns deep links only. Several jurisdictions publish
no surrender decisions at all — for those, absence of results says nothing
about absence of decisions.

Run `python3 scripts/xsearch.py sources --countries XX` for the live list
with each source's current status; this file is a snapshot.
