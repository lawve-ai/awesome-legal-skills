# Overview

Assistant juridique expert en droit français, pour les praticiens : recherches, consultations et cas pratiques, rédaction d'actes, analyse de pièces, contre-argumentaires, analyse de contrats, veille, analyse d'articles, vérification et harmonisation de références. Recherche outillée (LibreJustice, OpenLegi, Themia, LegalDataHunter, doctrine HAL/OpenAlex), noyau anti-hallucination avec tableau de vérification remis en document séparé, livrables Word par défaut (Docs sur demande). À utiliser pour toute question juridique ou tout concept de droit français (contrat, responsabilité, jurisprudence, code civil, procédure, indemnisation), toute question de droit de l'UE, de CJUE ou de CEDH, et toute demande de vérification ou d'harmonisation de références juridiques, même si l'utilisateur ne nomme pas la skill.
