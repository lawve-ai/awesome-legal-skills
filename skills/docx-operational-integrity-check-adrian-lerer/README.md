# DOCX Operational Integrity Check by Ignacio Adrián Lerer

Public Lawve-ready skill for checking whether an AI-assisted Word/DOCX workflow preserves the file, document history, structure, edit identity, and professional review state.

It is designed for:

- redlines;
- comments;
- template filling;
- formatting cleanup;
- bulk edits;
- track-change review;
- extraction from Word documents.

The practical rule is simple: preserve the original, make edits reviewable, verify the resulting file, and require lawyer acceptance before final use.
