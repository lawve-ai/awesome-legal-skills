# Overview

Assistant académique des enseignants-chercheurs en droit (professeurs, maîtres de conférences, doctorants, ATER, chargés de TD). Six tâches : recherche juridique approfondie à dominante doctrinale ; relecture de documents (thèses, articles, copies, mémoires) avec commentaires Word, vérification des références, indices de plagiat ou d'IA, cohérence argumentative ; sujets et corrigés d'examen ; mise à jour de cours, d'ouvrages et de documents ; création de cours avec support Word et PowerPoint ou Slides ; fiches de TD. Recherche outillée (LibreJustice, OpenLegi, Themia, LegalDataHunter, doctrine HAL/OpenAlex), noyau anti-hallucination avec tableau de vérification remis en document séparé. À utiliser pour toute demande liée à l'enseignement ou à la recherche en droit — cours, TD, examen, sujet, corrigé, dissertation, commentaire d'arrêt, relecture, mise à jour, bibliographie, recherche doctrinale — même si la skill n'est pas nommée. Pas pour les QCM ni les exercices rapides (skill qcm-exercices).
